# Third-party code

- `userlm_training/llama-cookbook/` is a reduced and modified copy of Meta's
  [llama-cookbook](https://github.com/meta-llama/llama-cookbook) (MIT License, see its `LICENSE`),
  keeping the FSDP fine-tuning path, checkpoint utilities, and a dataset loader for user-model samples.

The AI Observatory annotation framework (Longpre et al., 2026) is not included; install it separately
(see the README). Datasets and model weights are not included; their own licenses and terms of use apply.
